# پورتال انجمن مهندسی کامپیوتر زند

**Zand CE Hub** درگاه مرکزی مسیرهای یادگیری، برنامه‌ها، سندهای حاکمیت و خروجی‌های آموزشی انجمن مهندسی کامپیوتر مؤسسه آموزش عالی زند شیراز است.

🌐 **[ورود به پورتال و کاتالوگ ۱۰ مسیر یادگیری](https://shaiinarab.github.io/zand-ce-association/)** · [مسیرهای یادگیری](https://shaiinarab.github.io/zand-ce-association/programs/)

> وضعیت برنامه‌ها و اسناد، پیش‌نویس پیشنهادی است. انتشار وب‌سایت به‌معنی تصویب رسمی انجمن، تأیید زمان‌بندی یا وابستگی به ACM/IEEE نیست. نام رسمی، مجوزها، استاد مشاور و مسئول هر فعالیت باید توسط مراجع مربوط تأیید شوند.

## اکوسیستم آموزشی

پورتال مرکزی ده مسیر را در یک کاتالوگ گرد هم می‌آورد:

1. هوش مصنوعی و خلاقیت دیجیتال — [Workshop Zero](https://shaiinarab.github.io/workshop-zero/index.html)
2. سیستم‌عامل و زیرساخت — [Bootcraft](https://shaiinarab.github.io/bootcraft-workshops/)
3. بلاکچین و DeFi — [آخرین قطرات هایپ](https://shaiinarab.github.io/crypto-hype-last-drops/)
4. مهندسی نرم‌افزار و برنامه‌نویسی
5. بازی‌سازی
6. اینترنت اشیا و سیستم‌های نهفته
7. روباتیک
8. امنیت سایبری
9. رقابت‌های فتح پرچم (CTF)
10. شبکه و زیرساخت

**[مشاهده کاتالوگ کامل مسیرها](https://shaiinarab.github.io/zand-ce-association/programs/)**

سه پروژه موجود، مرجع اجرایی مستقل خود را حفظ می‌کنند؛ پورتال Zand CE Hub مسیر کشف، معرفی و دسترسی یکپارچه را فراهم می‌کند. سرفصل هفت مسیر جدید در `02-workshops/path-*.md` نگه‌داری می‌شود.

## نقشه پورتال

- `/` — صفحه اصلی، برنامه‌ها، دیوار خروجی و معرفی انجمن
- `/programs/` — کاتالوگ یکپارچه ده مسیر یادگیری
- `/programs/crypto-hype/` — معرفی کارگاه بلاکچین و DeFi
- `/docs/` — جست‌وجو و مرور سندها در هفت حوزه
- `/docs/workshops/<path>/` — طرح کامل مسیرهای آموزشی
- `/roadmap/` — نقشه راه و دروازه‌های تصمیم
- `/terminal/` — ترمینال محلی مرور سندها

## شروع محلی

نیازمندی: Node.js 22 یا جدیدتر.

```bash
npm ci
npm run check
npm run typecheck
npm run dev
```

برای ساخت خروجی ایستا:

```bash
npm run build
```

فایل‌های انتشار در `out/` ساخته می‌شوند.

## GitHub Pages

استقرار اصلی با GitHub Actions انجام می‌شود. workflow در `.github/workflows/pages.yml` قرار دارد و با هر push به `main` اجرا می‌شود. تنظیم Pages در مخزن باید روی **GitHub Actions** باشد.

- [وضعیت Actions](https://github.com/Shaiinarab/zand-ce-association/actions)

## اصول محتوا و حریم خصوصی

- اطلاعات اعضا، راه تماس، فرم‌ها و رضایت‌نامه‌ها را در مخزن عمومی نگه ندارید.
- فرم صفحه اصلی فعلاً فقط پیش‌نمایش محلی است؛ چیزی ارسال یا ذخیره نمی‌شود.
- برای محتوای دارای صدای/تصویر اشخاص، پیش از ضبط و انتشار رضایت و مجوز لازم است.
- هر برنامه باید مالک، هدف، خروجی، پشتیبانی و معیار ارزیابی روشن داشته باشد.
- فعالیت فاقد مسئول، مجوز یا حداقل پشتیبانی متوقف یا به تعویق می‌افتد.
- تمرین‌های امنیتی و CTF فقط در محیط ایزوله و با مجوز صریح انجام می‌شوند.
- فعالیت‌های IoT و روباتیک باید با محدودیت توان، تجهیزات ایمن و نظارت آزمایشگاه طراحی شوند.

## ساختار مخزن

- `00-governance`: منشور، نقش‌ها، نقشه راه و ثبت تصمیم
- `01-orientation`: معارفه و متن ارائه
- `02-workshops`: کاتالوگ و طرح مسیرهای آموزشی
- `03-podcast`: پایلوت و رضایت‌نامه
- `04-alumni-mentoring`: منتورینگ و گردهمایی
- `05-operations`: فرم‌ها، شاخص‌ها، حریم خصوصی و تداوم
- `06-research`: منابع و پرسش‌های باز
- `app/` و `components/`: پورتال Next.js
- `public/`: دارایی‌های عمومی و پلی‌بوک

## مشارکت

پیشنهاد فعالیت را از قالب Issue در GitHub ثبت کنید. اطلاعات شخصی، کلیدها، گذرواژه‌ها یا داده‌های خصوصی را در Issue، Commit یا این مخزن عمومی قرار ندهید. پیش از تغییر محتوای رسمی، وضعیت پیش‌نویس و نیاز به تأیید را حفظ کنید.

مجوز و حقوق محتوای شخص ثالث باید برای هر دارایی جداگانه بررسی شود؛ این مخزن مجوز استفاده از آثار متعلق به دیگران را اعطا نمی‌کند.
