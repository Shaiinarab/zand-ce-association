# پورتال انجمن مهندسی کامپیوتر زند

**Zand CE Hub** دروازه مشترک برنامه‌ها، سندهای حاکمیت و خروجی‌های آموزشی انجمن مهندسی کامپیوتر مؤسسه آموزش عالی زند شیراز است.

<https://shaiinarab.github.io/zand-ce-association/>

> وضعیت این مخزن و اسناد آن پیش‌نویس پیشنهادی است. انتشار عمومی وب‌سایت به‌معنی تصویب رسمی انجمن، تأیید تمام برنامه‌ها یا وابستگی به ACM/IEEE نیست. نام رسمی، مجوزها، استاد مشاور و مسئول هر فعالیت باید توسط مراجع مربوط تأیید شوند.

## سه مسیر عملی

| برنامه | تمرکز | وب‌سایت |
|---|---|---|
| کارگاه صفر | هوش مصنوعی کاربردی، آفرینش دیجیتال، توسعه و پژوهش | [ورود به کارگاه صفر](https://shaiinarab.github.io/workshop-zero/index.html) |
| بوت‌کرفت | محیط توسعه، سیستم‌عامل، مجازی‌سازی و بازیابی امن | [ورود به بوت‌کرفت](https://shaiinarab.github.io/bootcraft-workshops/) |
| آخرین قطرات هایپ ارز دیجیتال | بلاکچین، DeFi، AMM و هوشمندی داده‌های آن‌چین | [ورود به کارگاه](https://shaiinarab.github.io/crypto-hype-last-drops/) |

## کارگاه‌ها و رویدادها

فهرست یکپارچه کارگاه‌ها و ترتیب اجرایشان در [02-workshops/README.md](02-workshops/README.md) است.
نقشه کامل رویدادها (سرفصل‌ها، خروجی ارزیابی و منابع اولیه هرکدام) در
`projects/Uni/event.md` نگه‌داری می‌شود؛ عنوان‌ها و بسته‌بندی دوره‌های خصوصی در
`projects/Uni/private-courses.md` (داخلی) است.

## نقشه پورتال

- `/` — صفحه اصلی، برنامه‌ها، زنجیره بوت، دیوار خروجی و فرم نمایشی علاقه‌مندی
- `/programs/crypto-hype/` — معرفی کارگاه بلاکچین و DeFi
- `/docs/` — جست‌وجو و مرور سندها در هفت حوزه
- `/docs/<حوزه>/<سند>/` — متن کامل سند با فهرست بخش‌ها و ناوبری قبلی/بعدی
- `/roadmap/` — نقشه راه ۹۰ روزه و دروازه‌های تصمیم
- `/terminal/` — ترمینال محلی مرور سندها

## شروع محلی

نیازمندی: Node.js 22 یا جدیدتر.

```bash
npm ci
npm run check
npm run typecheck
npm run dev
```

برای ساخت خروجی ایستا:

```bash
npm run build
```

فایل‌های انتشار در `out/` ساخته می‌شوند.

## GitHub Pages

استقرار اصلی با GitHub Actions انجام می‌شود. workflow در `.github/workflows/pages.yml` قرار دارد و با هر push به `main` اجرا می‌شود. تنظیم Pages در مخزن باید روی **GitHub Actions** باشد.

- [وضعیت Actions](https://github.com/Shaiinarab/zand-ce-association/actions)
- [تنظیمات Pages](https://github.com/Shaiinarab/zand-ce-association/settings/pages)
- [وب‌سایت منتشرشده](https://shaiinarab.github.io/zand-ce-association/)

## اصول محتوا و حریم خصوصی

- اطلاعات اعضا، راه تماس، فرم‌ها و رضایت‌نامه‌ها را در مخزن عمومی نگه ندارید.
- فرم صفحه اصلی فعلاً فقط پیش‌نمایش محلی است؛ چیزی ارسال یا ذخیره نمی‌شود.
- برای پادکست و محتوای دارای صدای/تصویر اشخاص، پیش از ضبط و انتشار رضایت و مجوز لازم است.
- برنامه‌ها باید مالک، هدف، خروجی، پشتیبانی و معیار ارزیابی روشن داشته باشند.
- فعالیت فاقد مسئول، مجوز یا حداقل پشتیبانی متوقف یا به تعویق می‌افتد.

## ساختار مخزن

- `00-governance`: منشور، نقش‌ها، نقشه راه و ثبت تصمیم
- `01-orientation`: معارفه و متن ارائه
- `02-workshops`: نقشه آموزشی، ایمنی و طرح کارگاه‌ها

- `public/`: دارایی‌های عمومی و پلی‌بوک

## مشارکت

پیشنهاد فعالیت را از قالب Issue در GitHub ثبت کنید. اطلاعات شخصی، کلیدها، گذرواژه‌ها یا داده‌های خصوصی را در Issue، Commit یا این مخزن عمومی قرار ندهید. پیش از تغییر محتوای رسمی، وضعیت پیش‌نویس و نیاز به تأیید را حفظ کنید.

مجوز و حقوق محتوای شخص ثالث باید برای هر دارایی جداگانه بررسی شود؛ این مخزن مجوز استفاده از آثار متعلق به دیگران را اعطا نمی‌کند.
