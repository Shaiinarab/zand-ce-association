# کارگاه اول: از صفر تا اجرای یک پروژه
وضعیت پیشنهادی؛ ۱۲۰ دقیقه؛ سطح مقدماتی.
پیش‌نیاز: بررسی دستگاه و پشتیبان‌گیری؛ فایل‌های آموزشی از قبل آماده؛ یک زبان و یک پروژه آزمایش‌شده توسط مدرس.
## هدف قابل مشاهده
هر شرکت‌کننده بتواند پروژه نمونه را اجرا کند، تغییری ایجاد کند و روش اجرا را بنویسد.
## زمان‌بندی
- ۰–۱۵: تشخیص محیط و مسیر جایگزین
- ۱۵–۳۵: ساختار پروژه، ترمینال و مسیرها
- ۳۵–۶۵: دریافت و اجرای پروژه
- ۶۵–۸۰: استراحت و رفع اشکال
- ۸۰–۱۰۵: تغییر کوچک و ثبت در Git
- ۱۰۵–۱۲۰: نمایش خروجی و ارزیابی
## ارزیابی
اجرای پروژه؛ یک تغییر؛ یک commit؛ README قابل فهم. حضور به تنهایی تکمیل محسوب نشود.
## پشتیبانی
پیشنهاد اولیه یک دستیار به ازای ۶ تا ۸ دستگاه؛ پس از پایلوت اصلاح شود. دستگاه جایگزین یا کار دونفره پیش‌بینی شود.
