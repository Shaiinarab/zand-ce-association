# مسیر شبکه و زیرساخت

**شناسه مسیر:** NET · **سطح:** مقدماتی تا پیشرفته · **وضعیت:** طرح آموزشی

## هدف

فهم مسیر حرکت داده از یک دستگاه تا سرویس مقصد و توانایی طراحی، پیکربندی، عیب‌یابی و مستندسازی یک شبکه کوچک.

## نقشه یادگیری

| مرحله | موضوع‌ها | تمرین و خروجی |
|---|---|---|
| ۱. مبانی | مدل‌های TCP/IP و OSI، Ethernet، MAC و frame | ترسیم مسیر یک درخواست |
| ۲. آدرس‌دهی | IPv4، subnet، CIDR، gateway و IPv6 | طراحی طرح آدرس‌دهی |
| ۳. سوئیچینگ | switching، VLAN، trunk و broadcast domain | شبکه چند VLAN در شبیه‌ساز |
| ۴. مسیریابی | route، static routing، NAT و مفهوم dynamic routing | ارتباط دو subnet |
| ۵. سرویس‌های پایه | DHCP، DNS، NTP و HTTP | راه‌اندازی سرویس محلی |
| ۶. شبکه لینوکس | interface، route، firewall، socket و ابزار عیب‌یابی | گزارش تشخیص قطعی ارتباط |
| ۷. امنیت و پایش | segmentation، ACL، VPN، packet capture و logging | سیاست دسترسی و تحلیل ترافیک |
| ۸. زیرساخت | virtualization، container networking، reverse proxy و backup | شبکه آزمایشگاهی مستند |

## ابزارهای پیشنهادی

Wireshark برای مشاهده ترافیک، ابزارهای خط فرمان سیستم‌عامل، GNS3 یا Containerlab برای آزمایش توپولوژی، و ماشین مجازی یا کانتینر برای سرویس‌های محلی. انتخاب ابزار به امکانات آزمایشگاه وابسته است.

## پروژه نهایی

طراحی و پیاده‌سازی شبکه‌ای کوچک با حداقل دو subnet، سرویس DNS و DHCP محلی، سیاست دسترسی، ثبت وضعیت و مستندات عیب‌یابی. تمام اجزا باید در محیط آزمایشگاهی قابل بازسازی باشند.

## ایمنی و حریم خصوصی

Packet capture فقط روی شبکه و دستگاه‌های مجاز انجام می‌شود. ترافیک کاربران، رمزها و داده شخصی نباید ضبط یا منتشر شوند. تمرین‌های تغییر پیکربندی روی شبکه ایزوله یا شبیه‌ساز انجام می‌شوند؛ هیچ تغییر آزمایشی روی شبکه عملیاتی دانشگاه بدون مجوز و برنامه بازگشت انجام نمی‌شود.
