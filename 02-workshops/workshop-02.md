# کارگاه دوم: محیط قابل تکرار و اشکال‌زدایی
وضعیت پیشنهادی؛ ۱۲۰ دقیقه؛ ادامه پروژه جلسه قبل.
## هدف
تشخیص یک خطای مسیر/وابستگی، اجرای تست و بازسازی محیط از روی مستندات.
## زمان‌بندی
- ۰–۱۵: مرور خطاهای واقعی جلسه قبل
- ۱۵–۴۰: تفاوت سیستم‌عامل، shell، runtime و وابستگی
- ۴۰–۷۰: یک خطای عمدی و حل مستند آن
- ۷۰–۹۰: اجرای تست و بازبینی کد تولیدشده با AI در صورت انتخاب مدرس
- ۹۰–۱۱۰: اجرای پروژه توسط هم‌تیمی از روی README
- ۱۱۰–۱۲۰: بازخورد و انتخاب موضوع بعدی
## توسعه اختیاری
Dev Container فقط برای دستگاه مناسب و با راه جایگزین. معرفی همه ابزارها در یک جلسه هدف نیست.
## معیار تکمیل
هم‌تیمی بتواند پروژه را اجرا کند؛ یک خطا توضیح داده شود؛ حداقل یک تست عبور کند.
