# مسیر امنیت سایبری و دفاع دیجیتال

**شناسه مسیر:** CYBER · **سطح:** مقدماتی تا پیشرفته · **وضعیت:** طرح آموزشی

## هدف

آموزش تفکر امنیتی برای ساخت، نگه‌داری و دفاع از سامانه‌ها؛ از مدل تهدید و سخت‌سازی سیستم تا تحلیل رخداد و آزمون کنترل‌شده آسیب‌پذیری.

## نقشه یادگیری

| مرحله | موضوع‌ها | تمرین و خروجی |
|---|---|---|
| ۱. مبانی امنیت | محرمانگی، یکپارچگی، دسترس‌پذیری، ریسک و مدل تهدید | threat model برای یک برنامه نمونه |
| ۲. امنیت سیستم | کاربران، مجوزها، patching، سرویس‌ها و لاگ | چک‌لیست hardening لینوکس آزمایشگاهی |
| ۳. امنیت وب | HTTP، session، ورودی، کنترل دسترسی و خطاهای رایج | بررسی اپلیکیشن عمداً آسیب‌پذیر |
| ۴. رمزنگاری کاربردی | hash، امضا، کلید عمومی، TLS و مدیریت secrets | تشخیص کاربرد درست hash و encryption |
| ۵. امنیت شبکه | segmentation، firewall، DNS و پایش ترافیک | طراحی rule و تحلیل capture آزمایشگاهی |
| ۶. آسیب‌پذیری و وصله | CVE، شدت، بازتولید، اولویت‌بندی و remediation | گزارش فنی همراه با راه اصلاح |
| ۷. پایش و پاسخ | log، alert، triage، containment و recovery | گزارش رخداد شبیه‌سازی‌شده |
| ۸. چرخه امن توسعه | dependency، code review، SAST و secret scanning | pipeline بررسی امنیتی |

## چارچوب‌ها و منابع

OWASP برای امنیت برنامه وب، NIST برای مدیریت ریسک و پاسخ رخداد، و مستندات رسمی سیستم‌عامل‌ها و ابزارها مبنای مطالعه‌اند. ابزار تنها وقتی معرفی می‌شود که هدف آموزشی و محدوده استفاده‌اش روشن باشد.

## پروژه نهایی

ارزیابی امنیتی یک برنامه آزمایشگاهی تحت مالکیت برگزارکننده، شامل محدوده مجاز، یافته‌های بازتولیدپذیر، شدت، شواهد غیرحساس و راهکار اصلاح.

## مرز مجاز

تمام اسکن‌ها و آزمون‌ها فقط روی ماشین‌های شخصی، آزمایشگاه ایزوله یا سامانه‌ای انجام می‌شوند که مجوز صریح و محدوده مکتوب آن وجود دارد. اسکن شبکه دانشگاه، حساب دیگران، وب‌سایت عمومی یا زیرساخت اشخاص بدون مجوز ممنوع است. سرقت اعتبارنامه، persistence، تخریب داده و دسترسی غیرمجاز موضوع تمرین نیستند.
