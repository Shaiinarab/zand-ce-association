# مسیر رقابت‌های امنیتی و فتح پرچم (CTF)

**شناسه مسیر:** CTF · **سطح:** مقدماتی تا پیشرفته · **وضعیت:** طرح آموزشی

## هدف

تبدیل مفاهیم امنیت و علوم کامپیوتر به مسئله‌های رقابتی، قابل داوری و قابل بازبینی. این مسیر مکمل امنیت سایبری است: CTF مهارت حل چالش را می‌سنجد، درحالی‌که مسیر امنیت بر طراحی و دفاع سامانه تمرکز دارد.

## دسته‌های اصلی چالش

| دسته | مهارت | نمونه خروجی |
|---|---|---|
| Web | تحلیل ورودی، session و کنترل دسترسی | write-up آسیب‌پذیری در برنامه آزمایشگاهی |
| Cryptography | ریاضی پیمانه‌ای، encoding، hash و رمزنگاری | حل چالش و توضیح ضعف فرضی |
| Forensics | بررسی فایل، metadata، حافظه و timeline | گزارش شواهد و روش استخراج |
| Reverse Engineering | خواندن ساختار باینری و منطق برنامه | تحلیل رفتار فایل نمونه |
| Pwn | حافظه، stack، ورودی و خطاهای برنامه | حل محیط آموزشی sandbox شده |
| OSINT | جست‌وجوی منابع عمومی و اعتبارسنجی شواهد | گزارش با منبع و محدودیت |
| Misc | scripting، منطق، encoding و مسئله‌های ترکیبی | راه‌حل مستند و قابل تکرار |

## نقشه یادگیری

1. آشنایی با قوانین، scoring، flag format و اخلاق رقابت
2. خط فرمان، Python پایه، encoding و کار با فایل
3. مبانی شبکه، HTTP، سیستم‌عامل و حافظه
4. حل چالش‌های مقدماتی دسته‌بندی‌شده
5. نوشتن اسکریپت‌های کمکی و ثبت روش حل
6. چالش‌های ترکیبی و تیمی
7. ساخت challenge و test کردن آن
8. شرکت در رویداد داخلی و ارائه write-up

## زیرساخت پیشنهادی

پلتفرم CTFd یا نمونه مشابه، ماشین‌های مجازی disposable، شبکه داخلی محدود و challengeهای self-hosted. هر چالش باید سطح، دسته، هدف، محدودیت، flag، راهنمای برگزارکننده و روش reset داشته باشد.

## پروژه نهایی

تیم‌ها یک چالش آموزشی طراحی می‌کنند، آن را در محیط ایزوله آزمایش می‌کنند و همراه با راه‌حل، معیار امتیازدهی و راهنمای یادگیری منتشر می‌کنند.

## قواعد رقابت

فقط زیرساخت و هدف‌هایی که برگزارکننده صریحاً معرفی کرده مجازند. حمله به زیرساخت میزبان، سرویس بیرونی، حساب واقعی یا شرکت‌کنندگان دیگر ممنوع است. انتشار flag یا write-up پیش از پایان رقابت تابع قوانین رویداد است. برای OSINT، اطلاعات حساس اشخاص هدف قرار نمی‌گیرد.
