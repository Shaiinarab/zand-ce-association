# چک‌لیست ایمنی و دسترسی
- [ ] مدرس روی دستگاه آزمایشی مراحل را اجرا کرده است.
- [ ] فضای دیسک، نسخه سیستم و مجوز نصب بررسی شده؛ گزارش شامل نام کاربری/سریال نیست.
- [ ] فایل شخصی و رمز شرکت‌کننده کپی یا درخواست نمی‌شود.
- [ ] پشتیبان‌گیری و پیام خطر تغییر سیستم توضیح داده شده است.
- [ ] در جلسات مقدماتی پارتیشن‌بندی و dual boot زنده اجرا نمی‌شود.
- [ ] تغییر BIOS، Secure Boot یا رمزگذاری بدون بررسی موردی انجام نمی‌شود.
- [ ] ابزار ناشناس و اسکریپت اینترنتی بدون بازبینی با دسترسی مدیر اجرا نمی‌شود.
- [ ] فایل‌ها از منبع رسمی و در صورت ارائه، با checksum منتشرشده همان منبع کنترل می‌شوند.
- [ ] نسخه آفلاین مجاز، مسیر بدون حساب خارجی و دستگاه جایگزین پیش‌بینی شده است.
- [ ] نصب اجباری افزونه AI یا خرید اشتراک نداریم.
- [ ] برای فعالیت مبتنی بر cloud، دسترسی، هزینه و شرایط استفاده همان روز بررسی می‌شود.
- [ ] Dev Drive و تغییر اندازه دیسک تمرین عمومی مبتدی نیست؛ نیازهای خاص آن با مستند رسمی بررسی می‌شود.
منابع فنی: S4–S6. این چک‌لیست سیاست احتیاطی پیشنهادی است.
